# 参考图：标准、补图与修复

图生 3D 的输出质量上限由参考图决定。模型本身不会"想象"出图里没有的结构，
它只会把图里的东西挤出厚度。所以**先把图画对，再提交**。

## 合格参考图的六条硬标准

| 项 | 要求 | 不满足的后果 |
|---|---|---|
| 视角 | 正面，正对镜头 | 斜侧视角生成出歪斜的躯干，接进游戏后怎么转都不对 |
| 构图 | 全身，头到脚完整入画 | 只给半身会凭空补出一双比例失调的腿 |
| 姿势 | 站姿或四肢张开的自然姿势 | 抱臂/交叉腿会把两块网格焊在一起，动起来撕不开 |
| 背景 | 纯白或纯色，无杂物阴影 | 杂背景会被当成模型的一部分生成出来 |
| 分辨率 | 长边 ≥ 1024px | 五官、手指糊成一团 |
| 数量 | 一图一角色 | 双人合影会融成一个双头怪 |

补充：**服装细节越多越好**。AI 会照着服饰的明暗做出起伏，一件纯色 T 恤
生成出来就是一截圆柱；有领子、口袋、腰带的图，生成出来有明显的结构。

## 图不合格时：先补图，别硬跑

三种情况必须先处理：只有头像/半身、背景脏、分辨率太低。

### 半身补全身

用图生图（image-to-image），**不是重画**。关键是逐条写死特征，
否则会生成一个"同风格但不同人"的新角色。模板：

```
把这张角色头像扩展成完整的正面全身站姿，保持完全相同的人物特征：
发色 <具体色值/描述>、发型 <描述>、瞳色 <具体色>、服装 <逐件描述>、
配饰 <逐件描述>。
姿态自然站立、双臂垂放于身体两侧、正对镜头、双脚分开与肩同宽。
纯白背景，无阴影，全身完整入画，头到脚都不可裁切。
风格与参考图完全一致。
```

要点：

- `双臂垂放` 很重要。手举着/扶着腰的姿势，跑起来会像在挥手（见 pitfalls 6.3）
- `纯白背景` 让后续判断轮廓简单得多
- `不可裁切` 防止把脚切掉——这是最常见的补图失败
- 特征描述要落到具体：写"棕色"会被换成"金棕"，写"深栗色短发、齐耳"才稳

### 背景脏 / 有水印

- **水印落在画面上**（不是空白区）：用邻近区域采样颜色涂平。
  生成图常见右下角平台水印
- **不要用裁剪去水印**：裁剪会把鞋底、裙摆一起切掉，比水印更糟
- 背景有渐变或阴影：直接填成纯白，别保留

### 分辨率不够

先放大到长边 1024 以上再提交。放大算法用 LANCZOS。
放大后如果边缘出现振铃，先做一次轻度降噪——AI 会把振铃当成真实的曲面起伏。

## 参考图目录的组织建议

```
ref3d/
├── nailong.png          ← 待生成
├── zhuzhuxia.png
├── _src/                ← 补图中间产物、原图备份，脚本会跳过
│   └── 补全身_xxx.png
└── _draft.txt           ← 备注也可以，反正只看图片扩展名
```

`scripts/gen_actor_3d.py` 跳过**文件名以 `_` 开头**的文件。
这条规则是为了防止补图中间产物被当成参考图提交——每次提交都占额度，
误提交两张就等于白扔两次。

## 提交前的最后一眼

- [ ] 打开图，缩到 25% 看：整体剪影能不能一眼认出是谁
- [ ] 放大到 100% 看：眼睛、嘴、手指有没有糊
- [ ] 看四边：有没有被裁掉的部分
- [ ] 看角落：有没有水印
